Política de privacidade

Armazenamento local e controle do usuário.

Data de vigência: 28 de março de 2026. Última atualização: 18 de maio de 2026.

O Organizador de Saúde permite ao usuário organizar informações pessoais de saúde, como dados cadastrais, consultas, medicamentos, exames, resultados, observações e anexos adicionados manualmente.

Finalidade do aplicativo

O aplicativo é uma ferramenta de organização pessoal. Ele não é um dispositivo médico, não realiza diagnóstico, não trata, cura ou previne qualquer condição de saúde, não substitui consulta, acompanhamento ou orientação de um profissional de saúde e não deve ser usado para emergências médicas.

Dados que podem ser tratados

O aplicativo pode armazenar localmente dados informados pelo próprio usuário, incluindo nome, e-mail, telefone, data de nascimento, informações pessoais de saúde, consultas, medicamentos, exames, resultados, valores de referência, observações e anexos adicionados manualmente.

O aplicativo não solicita acesso a câmera, microfone, localização, contatos, sensores corporais, Health Connect ou outros dados de saúde de fontes externas.

Onde os dados ficam

Na versão atual, o aplicativo não coleta, transmite ou sincroniza dados com servidor online, nuvem pública, banco de dados remoto ou painel externo. Os dados de saúde e registros cadastrados permanecem armazenados localmente no dispositivo do usuário. Quando suportado pela plataforma, anexos são gravados na área privada do aplicativo.

Como os dados são utilizados

Os dados são utilizados somente para exibir e organizar registros dentro do próprio aplicativo, permitir cadastro, edição, consulta e exclusão de registros pelo usuário, mostrar resumos, alertas locais e comparações com valores de referência informados pelo usuário.

Coleta, acesso e compartilhamento

  • Não há acesso público aos dados cadastrados.
  • O desenvolvedor não acessa, visualiza, coleta ou acompanha as informações salvas no aplicativo.
  • Os dados não são vendidos.
  • Não há anúncios, analytics, rastreamento de marketing ou compartilhamento automático com terceiros.

Compartilhamento

O compartilhamento somente poderá ocorrer se o próprio usuário decidir mostrar, exportar, enviar ou compartilhar manualmente algum conteúdo, ou quando houver exigência legal, ordem judicial ou obrigação regulatória aplicável.

Segurança

São adotadas medidas técnicas razoáveis para reduzir acesso não autorizado, perda, alteração ou divulgação indevida de dados, incluindo armazenamento local no dispositivo e uso da área privada do aplicativo quando disponível. Como os dados ficam no dispositivo, a segurança também depende das configurações do aparelho.

Retenção e exclusão dos dados

Os dados permanecem armazenados enquanto forem mantidos pelo usuário no aplicativo. O usuário pode excluir registros dentro do aplicativo quando essa opção estiver disponível. Também pode excluir os dados locais ao desinstalar o aplicativo ou limpar os dados do app nas configurações do dispositivo.

Direitos do titular

O usuário pode acessar, corrigir, atualizar ou excluir os registros mantidos localmente diretamente no próprio aplicativo ou no dispositivo.

Crianças e adolescentes

O aplicativo não é direcionado especificamente a crianças menores de 13 anos sem supervisão do responsável legal.

Alterações desta política

Esta política poderá ser atualizada para refletir melhorias do produto, mudanças legais, regulatórias ou operacionais. A versão vigente será a publicada nesta página.
